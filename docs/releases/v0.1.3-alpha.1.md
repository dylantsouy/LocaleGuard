LocaleGuard checks multilingual layouts in Chromium. This Alpha adds local paint evidence for shallow text collisions, partial-scan diagnostics, and an offline review page with original and annotated screenshots.

## Install and scan

Download `localeguard-0.1.3-alpha.1.tgz` from **Assets** into a local npm project. Use Node.js 22, 24 or 26.

```sh
npm install --save-dev ./localeguard-0.1.3-alpha.1.tgz
npx playwright install chromium
```

Save the [sample config](https://github.com/dylantsouy/LocaleGuard/blob/v0.1.3-alpha.1/localeguard.config.json) as `localeguard.config.json`. Replace its localhost URLs with two language versions of the same page on a site you maintain. Then run:

```sh
npx --offline localeguard scan --config localeguard.config.json
```

Open the HTML path printed by the CLI. Each target reports its scan status. Each finding includes the rule, measurements and a screenshot. Exit code 1 means a completed scan found an error. Exit code 2 means an operational or coverage limitation needs attention.

## Alpha feedback

We're looking for 3–5 engineers who maintain multilingual sites. Try one page in two languages at desktop and mobile widths. Open the HTML report and tell us which layout you inspected, whether the result matched what you saw, and one thing that would make the report easier to use. A clean result or a reproducible installation failure is also useful. The feedback form accepts redacted examples. [Submit Alpha feedback](https://github.com/dylantsouy/LocaleGuard/issues/new?template=alpha-feedback.yml)

The release tarball is tested in clean consumer projects on Windows and Ubuntu across three Node.js versions. The checksum is included in `SHA256SUMS`. Independent field precision and recall are still unmeasured.
